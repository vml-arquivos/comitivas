================================================================================
INSTRUÇÕES PARA COOLIFY
================================================================================

1. ACESSAR COOLIFY
   - URL: https://seu-coolify.com
   - Faça login com suas credenciais

2. CRIAR NOVO SERVIÇO
   - Clique em "New Service"
   - Selecione "Docker Compose" ou "Node.js"
   - Conecte o repositório GitHub: vml-arquivos/comitivas

3. CONFIGURAR VARIÁVEIS
   - Vá para "Settings" > "Environment Variables"
   - Copie e cole TUDO acima (todas as linhas)
   - Clique em "Save"

4. CONFIGURAR DOMÍNIOS
   - Vá para "Settings" > "Domains"
   - Adicione: comitivas.permupay.com.br
   - Adicione: apicomitivas.permupay.com.br
   - Clique em "Save"

5. CONFIGURAR BUILD
   - Vá para "Build" > "Build Command"
   - Deixe como: npm run build (ou npm install)
   - Clique em "Save"

6. CONFIGURAR INICIALIZAÇÃO
   - Vá para "Start" > "Start Command"
   - Deixe como: npm start
   - Clique em "Save"

7. FAZER DEPLOY
   - Clique em "Deploy"
   - Aguarde a compilação (5-10 minutos)
   - Verifique os logs

8. VALIDAR DEPLOY
   - Acesse: https://comitivas.permupay.com.br
   - Acesse: https://apicomitivas.permupay.com.br/api/health
   - Verifique se retorna: {"status":"ok"}
